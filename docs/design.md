# Design notes

vitals is a gtfol app with lowercase copy and a quiet interface, built for one-handed set entry and live numbers you can read mid-set. These notes record where its visual language and native patterns come from, and what was deliberately left out.

## Sources reviewed

Reviewed on 2026-09-25 at these revisions:

- gtfol design standard: [gtfol/ai DESIGN.md at d42dc2e](https://github.com/gtfol/ai/blob/d42dc2ed9964fef2f2aa95149783fcaa58026e82/DESIGN.md). capsule's iPhone README links an earlier revision of the same file.
- capsule iPhone app: [gtfol/capsule apps/ios at 3c79797](https://github.com/gtfol/capsule/tree/3c7979737c43607608d2a2e7dd38924e4248394b/apps/ios) (target `CapsuleScan`, bundle ID `dev.gtfol.capsule`), and the web styles in `apps/web/src/app/globals.css`.
- freewrite iPhone and web apps: [gtfol/freewrite at a54ed50](https://github.com/gtfol/freewrite/tree/a54ed50dda4d0f3c96d29088d8b7871a506c3052), especially `apps/ios/Freewrite/UI` and `apps/web/components/bottom-nav.tsx`.
- HelioBar, read-only, for the Helio's standard services: [TirthCodes/HelioBar at 01b8b9c](https://github.com/TirthCodes/HelioBar/tree/01b8b9c5b780dc96ab3e75358476dc0e82b97598).

The live sites (capsule.gtfol.dev, freewrite.gtfol.dev, gtfol.dev) were blocked by the build environment's network policy, so the review used their source rather than the rendered pages.

gtfol/ai is a written standard with starting values for colors, type and spacing ("defaults for new work, not claims that the reference apps use every value"). It isn't a published token package, and vitals doesn't claim an official gtfol/ai specification.

From capsule's iPhone app: the `capsuleScreen()`-style screen modifier, the 2 pt-radius solid primary button, the information popover, plain toolbar items on iOS 26, text tabs in a bottom inset (capsule's version of freewrite's bottom bar), inline titles, open sections with thin dividers, 20 pt gutters, 44 pt targets, and dark-only appearance. Its engineering patterns carry over too: a committed project generated by a standard-library Python script and checked in CI, a dependency-free core compiled both by the app and by a SwiftPM test package, shared test files with `#if canImport`, an explicit-save SwiftData store with a launch-time repair step for interrupted work, a privacy manifest, and ad-hoc-signed simulator tests on macOS runners with Xcode 26.6.

From freewrite: a clock computed from timestamps (its session timer uses a deadline), tabular numbers, and the white-on-#111 single lowercase letter icon style.

## vitals' own choices

These aren't gtfol tokens:

- **Numbers you can read mid-set.** Live BPM is 56 pt, the workout and rest clocks 24 pt, set entry 20 pt. Lato's figures are tabular, so values don't shift as they change.
- **Heart rate stays small at the top.** Workout time, BPM, status, average and maximum, and a 36 pt chart fit in about 130 pt. The set log sits right below, and the rest clock sits above the tab bar within thumb reach.
- **Zone tint.** With an age, zones 4 and 5 tint the BPM (caution, then the error tone) and the zone number is always written out, so color is never the only signal. Zones 1–3 stay neutral. The copy says it's an approximation from 220 − age, not a measurement.
- **Set table.** Columns: set number (a menu for warm-up/working/delete), last time's set, load, reps, done. Fields clear on focus and show the current value as the prompt, so you type a new number without deleting the old one.
- **Bodyweight.** Zero load reads "bw", and added load on a bodyweight movement reads "bw + 20 lb".
- **Copy.** Lowercase, with other companies' names capitalized as capsule does ("Apple Health", "Zepp", "iPhone", "Bluetooth"), and Zepp's own menu labels quoted as they appear.

## Not taken from capsule, and why

- Camera, photo processing, sign-in, Keychain, server and REST clients, idempotency against a server, and PostHog analytics: vitals is offline, has no account, and collects nothing.
- Wardrobe models, category chips, product grids and fashion imagery: vitals is a training tool.
- The external payment link (`SupportLink`) and web legal links: not part of an offline v1.
- The `apps/ios` folder layout: this repository holds only the iPhone app, so the project is at the root.
- freewrite's system light/dark switching and iOS 26 target: vitals is dark-only like capsule, and targets iOS 17.
